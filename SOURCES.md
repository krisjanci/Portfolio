# Content provenance and design references

Reviewed November 12, 2026. The site intentionally distinguishes implemented features, personal prototypes, research findings, and planned work.

## Factual sources

- Desktop / Unorganised Documents / `Kristian_Janci_UPE_Application.pdf`: education, GPA, UPE membership, expected graduation, prior research, senior project methods, coaching and competitive tennis background. Career goals are not represented as employment history.
- Same folder / `Kristian Janci _ Blue and Gold Fair Resume (2).pdf`: downloadable resume, contact information, GitHub and LinkedIn links. This resume predates some newer native apps and should be updated.
- Same folder / `Econ Research Proposal - Kristian Janci.pdf`: SWELL-KW sample of 25 participants, early four-feature model MAE 13.246 against mean baseline 12.103, and the distinction between prediction and causal evidence of improved productivity.
- Same folder / `JuniorSeminarReport.pdf`: downloadable earlier Chrome-extension research report. Two-session self-study; mouse efficiency alone was not a reliable fatigue indicator.
- Same folder / `Face pic.jpg`: original portrait, copied without generative retouching or facial changes. The webpage crops it with CSS; the source file remains intact.
- Desktop / CS 600 / FocusFix-MacOS-App / `README.md`: implemented recording, work labels, breaks, review, export and deletion behavior; optional development sharing; current limits on fatigue and productivity claims. Its release status is older than the website's release note, so this portfolio links to the product site rather than asserting download availability.
- Desktop / CS 600 / FocusFix-Website / `README.md` and `docs/index.html`: product website, installation guide, branding, and future tutorial video. Icon copied from `docs/assets/focusfix.png`.
- Desktop / Personal Projects / Journal-Agent / `README.md`: local speech transcription, Foundation Models, SQLite, source retention, stale-analysis checks, concept search, and fallback behavior.
- Desktop / Personal Projects / Automation-Tools / Accord / `README.md`: on-device drafting and Gmail draft saving with human review; no sending.
- Desktop / Personal Projects / Automation-Tools / PostStudio / `README.md`: journal input, Vision observations, caption-based model input, editable drafts, manual posting.

LinkedIn URL is verified against the resume. The public LinkedIn page could not be retrieved in web research; no additional claims have been attributed to it. No messages were sent and no account actions were taken.

## Online portfolio research

These were consulted for design principles and information architecture. No code, copy, illustrations, or personal claims were copied.

- [Bruno Simon](https://bruno-simon.com/): a memorable interactive identity. Applied as a lightweight mathematical sculpture instead of a game that competes with the project content.
- [Brittany Chiang](https://brittanychiang.com/): accessible navigation, clear professional positioning, and specific project writing.
- [Andrej Karpathy](https://karpathy.ai/): a direct connection between identity, technical work, and accessible artifacts.
- [Chip Huyen](https://huyenchip.com/): clear paths into AI writing and work.
- [Joshua Ta](https://joshuataportfolio.com/): student/builder framing and project-specific technical evidence. The user's site does not borrow this portfolio's metrics or achievements.
- [Joseph Khemmoro](https://www.josephkhemmoro.com/): student entrepreneur portfolio discovered in search. Its live page exposed no readable content, so it did not inform detailed layout choices.
