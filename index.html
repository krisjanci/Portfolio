002 / JOURNAL AGENT

Voice in.
Structure out.

A personal macOS app for turning spoken entries into a journal you can revisit and search.

Audio→Transcript→Local analysis→SQLite

Engineering decisions

  • Apple’s Foundation Models run locally, with no cloud model fallback.
  • Original audio and transcripts are retained separately from generated summaries.
  • A transcript hash and analysis version prevent stale output from replacing newer edits.
  • Search uses AI-expanded concepts with deterministic matching and an explicitly labeled exact-text fallback. It is not an embedding database.

Current status

Personal prototype for supported Apple silicon Macs running macOS 26 or later. Public demo and source walkthrough are planned.

UP NEXT A synthetic-data demo and a measured retrieval evaluation.

003 / LOCAL AI TOOLS

Small surfaces.
Real workflows.

Accord

A native menu-bar utility that reads eligible Gmail messages, drafts replies using Apple Intelligence, and saves them to Gmail drafts for review. OAuth connects Gmail; the model runs on the Mac. The app does not send replies.

Post Studio

A local app that turns selected journal excerpts into editable LinkedIn, Instagram, and X post ideas. Apple Vision supplies tentative photo labels and OCR; the language model uses those observations and captions rather than viewing the photos directly. Publishing is manual.

What I’m exploring

Bounded model context, user review, recoverable local state, and useful fallback behavior when a model is unavailable.

004 / WORKLOAD PREDICTION

Evaluate before
you extrapolate.

Senior project at the intersection of behavioral data, machine learning, and economics.

Method

The SWELL-KW dataset contains computer-interaction measures from 25 participants. I’m comparing linear regression, ridge regression, random forests, and support vector regression against a mean baseline, using mean absolute error and participant-level validation.

Early result

The initial four-feature linear regression recorded MAE 13.246 versus 12.103 for the mean baseline. It did not improve on the baseline. These early numbers do not summarize the final comparison.

Limitations

Workload prediction is not validated fatigue detection. A small observational dataset cannot establish that taking a recommended break improves productivity. My earlier Chrome-extension self-study involved only two 45-minute sessions and found that mouse efficiency alone was not a reliable indicator.
